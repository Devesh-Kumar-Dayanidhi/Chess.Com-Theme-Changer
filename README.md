# Chess.Com-Theme-Changer
Browser extension that changes the theme of Chess.com to any custom theme.

This extension simply replaces these styles with custom styles:
     Play Against Human: <style type="text/css" id="board-styles-single">...</style>
     Analysis: <style type="text/css" id="board-styles-analysis-board">...</style>
     Play Against Computer: <style type="text/css" id="board-styles-play-computer">...</style>
     Puzzles: <style type="text/css" id="board-styles-primary">...</style>
     Lessons: <style type="text/css" id="board-styles-chessboard">...</style>

Feel free to change the theme to whatever you prefer!
