# Chess.Com-Theme-Changer
Browser extension that changes the theme of Chess.com to any custom theme.<br>

This extension simply replaces these styles with custom styles:<br>
     Play Against Human: <style type="text/css" id="board-styles-single">...</style><br>
     Analysis: <style type="text/css" id="board-styles-analysis-board">...</style><br>
     Play Against Computer: <style type="text/css" id="board-styles-play-computer">...</style><br>
     Puzzles: <style type="text/css" id="board-styles-primary">...</style><br>
     Lessons: <style type="text/css" id="board-styles-chessboard">...</style><br>
     Endgames Practice: <style type="text/css" id="board-styles-board">...</style><br><br>

Feel free to change the theme to whatever you prefer!<br>
